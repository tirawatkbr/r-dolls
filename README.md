# R Dolls — คลัง Supplier

เว็บสำหรับดูและเทียบซัพพลายเออร์ตุ๊กตาของทีม เข้าได้เฉพาะคนที่อยู่ในรายชื่อ

- **หน้าเว็บ:** https://tirawatkbr.github.io/r-dolls
- **ข้อมูล:** Supabase (Postgres + Storage)
- **สำรอง:** repo `r-dolls-data` (ส่วนตัว) สำรองอัตโนมัติทุกวัน

> repo นี้เป็น **สาธารณะ** เพราะ GitHub Pages ฟรีต้องใช้ repo สาธารณะ
> **ห้ามมีข้อมูลลูกค้า ราคา หรือกุญแจลับใด ๆ ใน repo นี้เด็ดขาด**
> ข้อมูลธุรกิจอยู่ใน Supabase และสำเนาอยู่ใน repo ส่วนตัวเท่านั้น

## สำหรับเพื่อนร่วมทีม

### เข้าเว็บครั้งแรก
1. เปิด https://tirawatkbr.github.io/r-dolls
2. กด **เข้าสู่ระบบด้วย Google** แล้วเลือกบัญชี Google ของคุณ
3. ถ้าขึ้นว่า "ยังไม่ได้รับสิทธิ์" แปลว่าอีเมลคุณยังไม่ถูกเพิ่ม — บอกเจ้าของคลังให้เพิ่มให้

ใช้ได้ทั้งคอมและมือถือ ไม่ต้องติดตั้งอะไร

### เพิ่ม supplier
กดการ์ด **＋ เพิ่ม supplier** ท้ายรายการ → พิมพ์ชื่อ → กรอกข้อมูลต่อในฟอร์มที่เด้งขึ้นมา

### เพิ่มรูป
- **บนคอม:** ลากไฟล์รูปมาวางบนการ์ด หรือในหน้ารายละเอียดได้เลย
- **บนมือถือ:** เปิดหน้ารายละเอียด → กด **🖼 เพิ่มรูป** → เลือกจากคลังภาพหรือถ่ายใหม่

รูปจะถูกย่อให้เหลือกว้างสุด 2400px อัตโนมัติก่อนอัป เพื่อให้เว็บโหลดเร็วบนเน็ตมือถือ

### ตั้งรูปปก / ลบรูป
เอาเมาส์ชี้ที่รูปในหน้ารายละเอียด จะมีปุ่ม **ตั้งเป็นปก** และปุ่มถังขยะโผล่มา

### สิ่งที่ควรรู้
- **ทุกคนเห็นข้อมูลชุดเดียวกัน** แก้อะไรเพื่อนเห็นทันทีที่กด Refresh
- **ดาว ★ เป็นของทีม** ไม่ใช่ของส่วนตัว — ใช้เป็น "เจ้าที่ทีมเล็งไว้"
- **ถ้ามีคนแก้เจ้าเดียวกันพร้อมกัน** คนที่บันทึกทีหลังจะขึ้นเตือนให้โหลดใหม่ ไม่มีการทับกันเงียบ ๆ
- **ลบแล้วยังกู้ได้** จากข้อมูลสำรองใน repo `r-dolls-data` (สำรองวันละครั้ง) — ทักเจ้าของคลัง

## สำหรับคนดูแล

### เพิ่ม/ถอนคน
Supabase → Table Editor → ตาราง `allowed_emails` → Insert row (ใส่อีเมล Google)
ถอนสิทธิ์ก็ลบแถวออก มีผลทันทีในการเรียกครั้งถัดไป

### โครงไฟล์
```
public/index.html     หน้าเว็บทั้งหมด (HTML + CSS + JS ในไฟล์เดียว)
public/config.js      URL กับ anon key ของ Supabase (เปิดเผยได้)
supabase/schema.sql   ตาราง + กฎ RLS — ไฟล์ที่แบกความปลอดภัยทั้งระบบ
scripts/migrate.mjs   ย้ายข้อมูลจากโฟลเดอร์เดิมขึ้น Supabase (รันครั้งเดียว)
```

### ทดสอบว่ากฎความปลอดภัยยังทำงาน
หน้าเว็บเป็นสาธารณะ กุญแจ `anon key` จึงเปิดเผยโดยการออกแบบ — ตัวกันจริงคือ RLS
**ทดสอบข้อนี้ทุกครั้งหลังแก้ `schema.sql`:**

```bash
curl -s "$SUPABASE_URL/rest/v1/suppliers?select=*" \
     -H "apikey: $ANON_KEY" -H "Authorization: Bearer $ANON_KEY"
```

ต้องได้ `[]` — ถ้าได้ข้อมูลออกมาคือ **ข้อมูลกำลังหลุดสู่สาธารณะ** ให้ปิดโปรเจกต์แล้วแก้ทันที
